Documentación de implementación para el sistema de captura de calificaciones escolares

Overview

El sistema permite a los maestros capturar, revisar e historial de calificaciones de sus grupos asignados. Cuenta con 3 pestañas principales:

01 · Grade Capture
Captura de calificaciones por parcial. Muestra la tabla de alumnos con Parcial 1, 2, 3 y promedio calculado.
02 · Student Receipt
Visualización y exportación a PDF del resumen de calificaciones del alumno. Incluye búsqueda por apellido.
03 · Change History
Bitácora de cambios de calificación: fecha, campo, valor anterior/nuevo, usuario y motivo.

Business Logic

Cálculo de promedio y estado

// Regla de negocio principal
function computeGrade(p1, p2, p3) {
  const average = (p1 + p2 + p3) / 3;
  const status  = average >= 6.0 ? 'approved' : 'failed';
  return { average: +average.toFixed(1), status };
}

// Ejemplo
computeGrade(7.5, 6.0, 8.0);
// → { average: 7.2, status: 'approved' }

computeGrade(4.0, 5.0, 6.5);
// → { average: 5.2, status: 'failed' }
REGLA

Aprobado si average ≥ 6.0. Reprobado si average < 6.0. El UI muestra verde para aprobado, rojo para reprobado.

Ordenamiento de lista de alumnos

COMPORTAMIENTO

Los alumnos se ordenan alfabéticamente por apellido. El número de lista (#) es el índice resultante de ese ordenamiento, no un campo persistido.

Historial de cambios (audit trail)

// Antes de actualizar una calificación, guardar en grade_history
async function updateGrade(gradeId, field, newValue, reason, userId) {
  const current = await db.findOne('grades', { id: gradeId });

  // 1. Insertar historial ANTES del update
  await db.insert('grade_history', {
    grade_id:     gradeId,
    changed_at:   new Date(),
    field_changed: field,               // "partial_1" | "partial_2" | "partial_3"
    old_value:    current[field],
    new_value:    newValue,
    reason:       reason,
    changed_by:   userId,
  });

  // 2. Actualizar la calificación
  const updated = { ...current, [field]: newValue };
  const { average, status } = computeGrade(
    updated.partial_1, updated.partial_2, updated.partial_3
  );
  await db.update('grades', { id: gradeId }, { [field]: newValue, average, status });
}

REST API Endpoints

Method Endpoint Descripción
GET /api/groups?teacher_id={id} Grupos y materia asignados al maestro
GET /api/groups/{id}/grades Lista de alumnos con sus calificaciones (Tab 1)
PUT /api/grades/{id} Actualiza un parcial. Body: { field, value, reason }
GET /api/grades/{id}/receipt Boleta del alumno (Tab 2). Acepta ?format=pdf
GET /api/grades/history?group_id={id} Historial de cambios del grupo (Tab 3)

PDF EXPORT

Al hacer click en "Imprimir PDF", llamar GET /api/grades/{id}/receipt?format=pdf. El backend genera el PDF con los datos de la escuela preconfigurados (nombre, logo, ciclo escolar) y lo retorna como application/pdf.
